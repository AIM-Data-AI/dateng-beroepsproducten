# README Beroepsproducten course Data Engineering

Deze repo bevat het materiaal voor de beroepsproducten van de course Data Engineering. Er zijn drie beroepsproducten: BP1, BP2 en BP3. Voor elk beroepsproduct vind je in de map `doc` een bestand `opdracht.md` met instructies.

Verder vind je in deze repo instellingen voor Python (zie install.sh, pyproject.toml en uv.lock) en een voorbeeld van het gebruik van Docker (in de map `voorbeeld-docker`).
